# 운때

생년월일시로 사주팔자를 세우고, 타로 3장을 뽑아 오행의 흐름으로 읽어주는 단일 페이지 웹앱입니다.

> **운때** — 표준국어대사전에 "운이 들어오는 때"로 실려 있는 우리말입니다.
> 사주는 태어난 순간에 고정된 **때**를, 타로는 지금 이 순간 뽑는 **운**을 봅니다.
> 이름 하나에 두 축이 다 들어갑니다.

**재미로 보는 페이지입니다.** 진로·건강·재정 등 실제 결정의 근거로 삼지 마세요.

## 특징

- **외부 의존성 0** — npm 패키지도, CDN도, 서버도 없습니다. `index.html`만 열면 동작합니다.
- **실시간 AI 호출 없음** — 해석 문장을 부품 단위로 준비해 두고 실행 시 조립합니다. 오프라인에서도 돌아갑니다.
- **한국 기준 보정 내장** — 서머타임, UTC+8:30 시기, 진태양시 경도 보정을 처리합니다.

## 왜 조합을 미리 다 만들지 않았나

- 사주 경우의 수: 년주 60 × 월주 12 × 일주 60 × 시주 12 = **518,400**
- 타로 3장(역방향 포함): 78 × 77 × 76 × 2³ = **3,651,648**
- 곱하면 약 **1.9조 가지** — 전수 생성이 불가능합니다.

그래서 문장을 부품으로 쪼개 약 200여 개만 준비하고, 실행 시 조립합니다.
사용자마다 조합이 달라져 맞춤형으로 읽힙니다.

`saju-core.js`는 다음을 거쳐 검증했습니다.

| 검증 항목 | 방법 | 결과 |
|---|---|---|
| 절기 시각 | astronomy-engine으로 태양 황경 독립 계산, 1900~2100년 4,824건 대조 | 평균 오차 12.6초 |
| 절기 시각 | 한국 공개 절기표(2024년 24개)와 분 단위 대조 | 24/24 일치 |

| 일주 기준점 | 1949-10-01 = 갑자일 앵커 | 일치 |
| 전체 | 무작위 30만 건 + 절기 경계 ±90분 6.2만 건 교차 검증 | 불일치 0건 |

### 한국 기준 보정

다른 만세력 라이브러리를 그대로 쓰면 틀리는 지점들입니다.

1. **표준시 변동** — 1954-03-21 \~ 1961-08-09 한국은 UTC+8:30을 썼고,
   1948\~51 · 1955\~60 · 1987\~88에는 서머타임이 있었습니다.
   브라우저 내장 IANA 시간대 데이터(`Intl`)로 자동 처리합니다.
2. **절기 경계** — 년주·월주는 절대 시각으로 절기와 비교하고,
   일주·시주는 동경 135도 기준 시각으로 판정합니다.
3. **진태양시** — 서울은 표준자오선(135°E)과 약 8도 차이라 약 32분 보정이 가능합니다. 선택 옵션입니다.

## 유파 선택

명리학계에서 의견이 갈리는 두 지점은 사용자가 고르게 했습니다.

- **야자시 / 조자시** — 23시부터 일주를 다음날로 볼지, 자정부터로 볼지
- **진태양시 보정** — 경도 차이를 반영할지

결과가 다른 만세력과 다르면 대개 이 설정 차이입니다. 계산 오류가 아닙니다.

## 음양오행 대응 근거

**전통에 근거한 부분**

- 오행의 성질과 오상 대응 (서경 「홍범」)
- 타로 수트의 원소 배정 (골든 던 전통: 완드=불, 컵=물, 소드=공기, 펜타클=흙)
- 원소 품위(Elemental Dignities) — 인접 카드의 원소 관계로 강약을 보는 기법
- 숫자 홀짝의 음양 구분
- 상생·상극 순서, 천간의 전통적 이미지

**창작한 부분**

- 수트를 오행으로 옮긴 연결 (완드=목, 소드=금 등)
- 역방향의 음양 반전
- 일간과 카드 오행의 십성 해석
- 해석 문장 전체
